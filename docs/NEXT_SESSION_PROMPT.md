# Vision 인터랙션 미니 프로젝트 — 구현 세션

## 컨텍스트

  - 우대: 공간기반 인터랙티브 콘텐츠 제작 경험
- 면접일: [입력] / 이번 세션 이후 쓸 수 있는 시간: [입력]

1. docs/DESIGN_DECISIONS.md를 끝까지 읽어 주세요. D0~D10은 확정된 결정이니 그 위에서 진행해요.
2. 구현하다가 확정된 결정과 부딪히는 근거가 나오면 원문은 그대로 두고, 선택지와 장단점으로 정리해서 제가 고르게 해 주세요. 부딪히지 않는 보강은 바로 반영하고 문서에 기록해 주세요.
3. docs/TROUBLESHOOTING.md의 형식을 확인해 주세요. 막힘이 생기면 그때그때 이 형식으로 기록해요.

## 진행 방식
- 열린 결정(DESIGN_DECISIONS.md §9)은 선택지와 트레이드오프를 먼저 설명하고, 권장안 하나와 근거로 마무리한 뒤 권장안으로 진행해 주세요. 다른 걸 원하면 제가 말할게요.
- 단, 나중에 바꾸기 어려운 결정(UE 프로젝트 이름·모듈 구조 등)은 제 답을 받고 진행해 주세요.
- 확실하지 않은 엔진·라이브러리 동작은 추측이라고 밝히고 확인 방법(소스 위치, 로그)을 같이 주세요. 기준 버전(UE 5.7.x, Python 3.11, 실제 설치된 mediapipe 버전)도 밝혀 주세요.
- 단계가 끝날 때마다 커밋하고, DESIGN_DECISIONS.md(새로 정한 것, 검증 결과, 변경 이력)와 TROUBLESHOOTING.md를 갱신해 주세요.
- 답변과 중간보고는 한국어 해요체로, 결론부터 써 주세요.

## 실행 환경 분담
- 웹캠과 Unreal은 제 Windows PC에서만 실행돼요. 제 PC에서 돌려야 하는 부분은 실행 명령과 기대 출력을 함께 주시면, 제가 실행해서 로그·에러를 붙여 드릴게요. (세션에서 제 PC에 직접 접근할 수 있으면 그 방법을 써도 돼요.)
- 세션 안에서 돌릴 수 있는 검증은 직접 돌려 주세요: One Euro 단위 테스트, OSC 인코딩/디코딩 루프백(송신부 ↔ 수신 테스트 스크립트), 장애 주입 옵션 동작처럼 웹캠 없이 돌아가는 부분이에요.

## 이번 세션 작업
### 1단계 — Python 송신부 (python/)
- 흐름: 캡처 스레드(최신 프레임 1칸) → Pose Landmarker(Tasks API, VIDEO 모드, lite 모델, num_poses=1) → One Euro(손별·축별) → OSC 송신(/dstrict/hands, 인자 10개, heartbeat)
- 장애 주입 옵션: --drop-rate, --freeze-after, --noise (노이즈는 필터 앞에 주입)
- 수신 테스트 스크립트: seq 유실률, 수신 주기(Hz), 좌표·신뢰도를 출력하고, 메시지가 D3 스키마·타입 태그와 정확히 일치하는지 검사해요. D3의 seq 재시작 규칙도 똑같이 따라야 해요.
- requirements.txt(버전 고정), 모델 다운로드 스크립트(.task는 커밋하지 않음), README 실행 방법 추가
- 코드 기준: 타입 힌트, dataclass 설정, argparse, logging. 카메라·소켓·landmarker는 컨텍스트 매니저나 finally로 해제를 보장하고, Ctrl+C로 깔끔하게 종료돼야 해요. 카메라 열기 실패 같은 오류는 원인이 보이는 메시지와 함께 안전하게 처리해 주세요.
- 완료 기준: 수신 테스트 스크립트에서 seq·좌표·신뢰도가 30Hz 근처로 들어오고, 장애 주입 옵션 3개가 의도대로 보여요.

### 2단계 — Unreal 수신부 (unreal/)
- 시작 전: 프로젝트 이름·위치·모듈 구조를 확정하고(제 답 필요), 생성 절차, OSC 플러그인 활성화, Build.cs 의존 모듈을 안내해 주세요.
- 먼저 확인: 엔진 OSC 플러그인 소스(Engine/Plugins/Runtime/OSC)에서 내부 큐·디스패치 스레드, Native 델리게이트 유무를 확인하고 결과를 DESIGN_DECISIONS.md D5에 기록해 주세요. 제 PC의 엔진 소스를 봐야 하면 파일 경로와 찾을 심볼을 알려 주세요.
- 수신 컴포넌트(ActorComponent): UOSCServer는 UPROPERTY로 보관하고, BeginPlay에서 Listen, EndPlay에서 Stop과 델리게이트 해제. 최신 값 1칸 덮어쓰기, 형식 검증(주소·인자 수·타입), seq 처리(재시작 초기화 규칙 포함).
- 상태 머신: D6 수치를 UPROPERTY(EditAnywhere)로 노출하고, 상태와 전환 사유를 화면 디버그로 표시. 전송 계층과 분리해서 "프레임 + 현재 시각"을 입력받는 형태로.
- 코드 기준: UE 코딩 표준(접두사, UPROPERTY/UFUNCTION 메타, const 정확성), 캡슐화(상태는 private, 필요한 getter만 BlueprintPure로 노출), 전용 로그 카테고리, 형식 오류·null에 안전한 폴백.
- 완료 기준: Python 송신부와 연결했을 때 상태 전환이 화면에 보이고, 시연 시나리오 1·2가 재현돼요.
